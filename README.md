# Repository structure
Script files are named in the sequencial order they have been run. Folder `ccs_r` and `mapeo_ciap_cie9` contain the dictionaries used to transform ICPC codes to ICD9 code, and lastly to CCS codes ([Clinical Classification Software](https://hcup-us.ahrq.gov/toolssoftware/ccs/ccs.jsp)[^1]). CCS is a diagnosis and procedure categorization scheme to reduce ICD9 classification into smaller, more meaningful, and mutually exclusive categories.
